# Local-only Business Discovery

This directory is intentionally excluded from Git.

It may contain local evidence and working materials such as email-derived notes,
customer mapping reviews, screenshots, raw exports, and historical report context.
Those files can include sensitive or frequently changing business data and must stay
on the user's computer.

Only this README is tracked. Repository assets may reference sanitized identifiers
and `${..._LOCAL_ONLY}` placeholders, but they must not require these local files as
cross-workflow output dependencies.
